# Code of conduct

## The short version

Be decent. Argue about the code, not the person.

## What is expected

- Assume the other person is trying to make the project better.
- Criticise work, not people. "This locks across IO" is useful; "this is
  sloppy" is not.
- Accept that a maintainer may say no. A project with no boundaries becomes
  everyone's and then nobody's.
- Say when you are unsure. Half this codebase's documentation exists because
  someone wrote down a thing they got wrong.

## What is not

Harassment, personal attacks, discrimination on any of the usual grounds,
sustained disruption, or publishing someone's private information.

## Enforcement

Report to **conduct@chuk.dev**. Reports are handled privately.

Responses run from a request to stop, through removal of a comment, to a ban
from the repository — chosen by what actually happened, and applied without
regard to how valuable somebody's contributions are.
