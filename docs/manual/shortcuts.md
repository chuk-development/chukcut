# Keyboard shortcuts

chukcut has three presets: **chukcut** (the default), **CapCut-like** and
**Premiere-like**. You can change every key.

## See the keys

The shortcuts sheet lists every action that has a key. Open it with:

- **Menu › Keyboard shortcuts**
- **Shortcuts** on the start screen
- `Ctrl+/` (chukcut and CapCut-like; the chukcut preset also has `?`), or `Ctrl+Alt+K` (Premiere-like)

## Change the keys

Open **Settings › Keyboard shortcuts › Edit shortcuts…**.

- **Search actions or keys** filters the list.
- **Preset** switches the base preset. Your own changes stay on top of the
  new preset.
- On each row:
  - **Change the key**: press the new key. `Esc` cancels.
  - **Add another key**: an action can have more than one key.
  - **No key**: removes the keys of the action.
  - **Back to the preset's key**: removes your change.
- A dot (•) marks a row that you changed.
- **Reset all** removes all your changes.

When the key that you press is in use, the editor says which action has it.
**Take it** moves the key to the new action. **Cancel** keeps it where it
is. A key that runs more than one action shows a red border, and a banner
lists the conflicts.

Keys without `Ctrl` or `Alt` (for example `S` or `Q`) do nothing while you
type in a text field. Copy, cut and paste in a text field act on the text,
not on the clips.

The keys are saved in `~/.config/chukcut/shortcuts.json`. They belong to
this computer, not to a project.

## All actions

Actions with "(none)" have no key in that preset. You can give them one.
Most of them are also in the clip's right-click menu.

## Keys that are not actions

These keys work in the timeline and are not in the editor:

| Key | What it does |
|---|---|
| Mouse wheel | scroll the time |
| `Ctrl` + wheel | zoom |
| `Shift` + wheel | scroll the lanes up and down |
| `Ctrl` + click | add a clip to the selection, or remove it |
| `Shift` + click | select along a lane |
| Double-click a title | edit its text on the timeline (`Enter` keeps, `Shift+Enter` new line, `Esc` cancels) |
| Double-click a compound clip | open it |
| Alt-click or right-click on the player | leave a part out of a selected object |
